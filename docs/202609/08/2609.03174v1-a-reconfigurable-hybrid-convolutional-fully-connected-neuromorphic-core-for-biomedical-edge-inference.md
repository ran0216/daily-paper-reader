## 摘要
本文提出了一种基于FPGA的可编程架构，用于脉冲卷积神经网络（SCNN）推理，以实时低氧分类作为生物医学边缘应用。该架构在一个可编程、量化、基于层的神经形态硬件核心上实现了混合脉冲卷积-全连接（CNN-FC）拓扑。早期层使用具有感受野连接的多通道卷积核和步长支持进行脉冲卷积，而深层则使用全连接脉冲层进行分类。基于PyTorch的软硬件协同设计流程通过量化和可配置性支持实现训练参数的部署。该设计首先在MNIST和Fashion-MNIST上验证，在16位精度下分别达到最高98%和86%的硬件准确率。随后，将其应用于低氧分类，使用从肩戴式传感器获取的红光和红外光电体积描记（PPG）信号，并将肤色作为附加输入通道。最终分类器在16位精度下，五折交叉验证平均硬件准确率达到88.26%，动态功耗为1.455 W，证明了在边缘进行低功耗神经形态生物医学分类的可行性。

## Abstract
This work presents a programmable FPGA-based architecture for spiking convolutional neural network (SCNN) inference, with real-time hypoxia classification serving as a biomedical edge application. The architecture implements a hybrid spiking convolutional-fully connected (CNN-FC) topology on a programmable, quantized, layer-based neuromorphic hardware core. Early layers perform spiking convolution using receptive-field connectivity with support for multi-channel kernels and stride, while deeper layers use fully connected spiking layers for classification. A PyTorch-based hardware-software co-design flow enables deployment of trained parameters with quantization and configurability support. The design is first validated on MNIST and Fashion-MNIST, achieving hardware accuracies of up to 98% and 86%, respectively, at 16-bit precision. It is then applied to hypoxia classification using red and infrared photoplethysmography (PPG) signals acquired from a shoulder-mounted sensor, with skin tone included as an additional input channel. The resulting classifier achieves an average hardware accuracy of 88.26% across five folds at 16-bit precision while consuming 1.455 W of dynamic power, demonstrating the feasibility of low-power neuromorphic biomedical classification at the edge.

## 2. 论文提出的方法论

**总体架构**：基于 QUANTISENC 可编程神经形态平台扩展出卷积层支持，构成统一的**混合 CNN–FC 脉冲网络硬件核心**。早期层做脉冲卷积特征提取，深层 FC 层负责分类。

**关键技术细节**：
- **LIF 神经元数字实现**：使用一阶泄漏积分发放模型，离散化更新为 `Vmem[t+1]=Vmem[t]−(Δt/τ)·Vmem[t]+(Δt/C)·Iin[t]`；支持阈值比较、三种重置模式（reset-to-zero、reset-by-subtraction、reset-to-constant）、可配置不应期、电压阈值、decay/growth 速率等运行时寄存器参数。
- **定点量化**：采用有符号定点数 `Q(n,q)`；权重可用更少的整数位 `Q(m,q)` 减小存储；所有加法、乘法、比较均在量化单元中完成，带溢出/下溢饱和。
- **FC 层突触访问**：每个后突触神经元独立的 BRAM 存 `F` 个权重，由 spike-gated 控制：只有输入 spike 有效时才读对应权重、做条件加法到部分和（MAC 退化为条件加法）。
- **卷积层突触访问与 MAC**：采用**共享核存储**，每个输入–输出通道对只用一个 `Kx×Ky` 的 BRAM；控制器用共享计数器遍历所有核权值并**全展开并行**计算所有输出位置。索引映射为 `idx = (wx·S+kx)·Yin+(wy·S+ky)`，同样以 spike 门控 `rd_en`，整个卷积只需要 `Kx×Ky` 个内存时钟周期完成。
- **系统集成**：CNN 输出展平后送入 FC 层；层配置通过编译期参数数组定义，运行时也可编程层内神经元参数；采用双时钟方案，内存时钟（memclk）驱动 MAC、spike 时钟（spkclk）驱动神经元动力学，跨时钟域用同步器处理。
- **多级可配置性**：在算术精度、神经元参数、CNN 层参数（核尺寸、步长、输入输出通道数）、FC 层参数、系统层数五个层面提供参数化支持，便于快速进行设计空间探索。
- **软硬件协同流程**：基于 PyTorch/snnTorch 训练网络，再通过自定义量化接口把训练好的参数部署到硬件。
- **低氧检测分类方案**：构建三类分类任务——Normal（SpO₂ 96–100%）、Moderate（92–95%）、Severe（88–91%）；输入为红光 PPG、红外 PPG 与肤色（skin tone）三个通道；数据经过带通滤波（0.5–3.0 Hz）、运动伪影剔除、信号质量过滤以及类别平衡下采样等预处理。

## 6. 主要结论与发现

- 提出的可编程混合 CNN–FC SCNN 硬件核心能有效支持可变量化与多级配置，完成图像与生物医学信号的低功耗边缘推理。

- **架构层面**：给出了一套同时支持卷积与全连接、且逐层可配的硬件模板，一改既往 FPGA SNN 加速器“FC-only 或 CNN-only”的二选一格局；其“共享核存储 + 全展开并行”设计为低功耗 CNN-SNN 混合推理提供了一个可复用的计算原语。
- **精度层面**：系统检验了 16/12/8-bit 定点量化下 SNN 硬件分类精度的衰减曲线，得出“12-bit 为精度—功耗折中甜点”的结论，对后续边缘 SNN 设计有直接的指导价值。
- **领域应用层面**：首次将 PPG 驱动的低氧严重度分类端到端部署到 FPGA SNN 硬件，打通了“临床数据 → 软件训练 → 量化 → 硬件部署 → 功耗评估”的完整链路，验证了神经形态硬件在心肺监护类可穿戴设备上的现实可行性。

## 10. 个人评价（含可复现性判断）

- **作为论文本身**：工作完成度高，工程实现有实质难度，选题对标真实临床痛点和明确的应用缺口；若有更完整的数据一致性校对和适量消融实验，完全可以投递更高一档的期刊/会议。

## 11. 总结论

本文面向边缘生物医学信号处理的实时低功耗推理需求，提出并实现了可编程的混合 CNN–FC 脉冲卷积神经网络硬件核，在 Xilinx UltraScale+ FPGA 上完成了 MNIST、Fashion-MNIST 及真实 PPG 低氧检测三类任务的部署验证。其核心贡献在于**把卷积支持、混合精度量化、运行时神经元参数配置与端到端软硬件协同流程统一到一个开放的可重构神经形态平台上**，并对低氧检测给出了首个硬件端到端部署结果（软件 89.1% vs 16-bit 硬件 88.26%，100 kHz 下动态功耗 1.455 W、每推理 727.5 μJ）。尽管在临床数据规模、消融对比、数字一致性与训练细节披露上存在不足，本文仍清晰地证明了脉冲卷积硬件在可穿戴低氧监护等低功耗边缘场景中的可行性。从工程价值角度看，其“12-bit 精度 + 数百 kHz 低频时钟”的工作点最有望成为未来 ASIC 化的基线设计；从学术价值角度看，它填补了面向生物医学信号的开放可重构 SNN CNN 加速器的空白，并为后续研究提供了一个可扩展的起点。
