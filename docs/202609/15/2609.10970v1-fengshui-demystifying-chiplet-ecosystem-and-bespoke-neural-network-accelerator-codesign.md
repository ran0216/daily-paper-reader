## 摘要
现代机器学习工作负载具有严格的延迟和能耗约束，越来越难以在同构的商用硬件上高效运行。我们认为，算子级解耦——为每个算子定制微架构、批处理和存储层次——对于克服这些限制至关重要，尽管由此产生的高度定制加速器会带来高昂到难以承受的非经常性工程（NRE）成本。基于芯粒的集成可将 NRE 成本分摊到多个应用，但选择构建哪些芯粒以及如何将它们组合成加速器存在循环依赖——芯粒池的价值取决于所构建的加速器，而加速器质量又受限于可用芯粒。本文提出 Fengshui，一种芯粒生态系统与加速器协同设计框架，可联合优化芯粒池组成与定制专用集成电路（BASIC）设计。Fengshui 通过算子级解耦构建 BASIC，协同探索芯粒与存储异构性、张量融合，以及流水线/张量/专家并行，并进行布局布线验证以确保物理可实现性。仅用 8 个经过策略性选择的芯粒（涵盖网络交换机、存内计算单元以及具有不同微架构的加速器），Fengshui 生成的 BASIC 相较于同构加速器，将能耗、能耗-成本积（EC）、能耗-延迟积（EDP）和能耗-延迟-成本积（EDPC）分别降低 48.5%、88.1%、93.0% 和 97.8%，同时在多种神经网络上，其得分与无约束异构设计相差不超过 4.1%。对于数据中心 MoE 和稠密 LLM 服务，Fengshui 将预填充能耗和 EC 分别最多降低 16.8% 和 28.7%；对于边缘自动驾驶车辆感知，在实时延迟约束下实现 12.0% 的能耗降低和 23.6% 的 EC 降低。

## Abstract
Modern ML workloads, with stringent latency and energy constraints, are increasingly hard to run efficiently on homogeneous commodity hardware. We argue that operator-level disaggregation--tailoring microarchitecture, batching, and memory hierarchy to each operator--is essential to overcome these limitations, though the resulting highly bespoke accelerators incur prohibitive Non-Recurring Engineering (NRE) costs. Chiplet-based integration amortizes NRE across applications, but choosing which chiplets to build and how to compose them into accelerators is circularly dependent--a chiplet pool's value depends on the constructed accelerators, while accelerator quality is constrained by available chiplets. This paper introduces Fengshui, a chiplet ecosystem and accelerator co-design framework that jointly optimizes chiplet pool composition and bespoke application-specific integrated circuit (BASIC) design. Fengshui constructs BASICs through operator-level disaggregation, co-exploring chiplet and memory heterogeneity, tensor fusion, and pipeline/tensor/expert parallelism with place-and-route validation for physical implementability. With just 8 strategically selected chiplets, encompassing network switches, processing-in-memory units, and accelerators with diverse microarchitectures, Fengshui-generated BASICs achieve 48.5%, 88.1%, 93.0%, and 97.8% reductions in energy, energy-cost product (EC), energy-delay product (EDP), and energy-delay-cost product (EDPC) over homogeneous accelerators, while scoring within 4.1% of unconstrained heterogeneous designs across diverse neural networks. For datacenter MoE and dense LLM serving, Fengshui reduces prefill energy and EC by up to 16.8% and 28.7%, respectively; for edge autonomous vehicle perception, it achieves 12.0% energy and 23.6% EC reductions under real-time latency constraints.

- **核心矛盾（NRE 困境）**：

## 2. 方法论

### 2.1 核心思想
- 每个 BASIC 实例化为**深层细粒度流水线**，每个流水级是一个"融合组"（fusion group），由一到多个算子组成，映射到为其定制的芯粒上。
- 芯粒共享内存端口时通过 **token passing** 仲裁（双缓冲下两芯粒交替、张量并行下时分共享），保证确定性且无饥饿。
- 目标函数可覆盖 energy、energy×$、EDP、EDP×$ 等多指标。

### 2.2 关键技术细节：四层嵌套协同设计

- **Layer 1：芯粒池搜索（SAEO + I-SAEO）**
  - 将芯粒池组成建模为组合优化问题（数据流 RS/WS/OS、PE 阵列大小、缓冲容量、DRAM 类型组合），候选空间随池大小指数增长。
  - **代理辅助进化优化（SAEO）**：进化搜索维护已评估池的 archive，每轮通过交叉（重组父代芯粒）与变异（扰动单个芯粒属性）产生约 2000 个后代；用在线 **Random Forest 代理模型**预筛选，仅将最有希望者送入下层完整评估。
  - **增量 SAEO（I-SAEO）**：池增长时冻结已有前缀，只变异新增芯粒，保证更大池"可证不劣于"小池；最后短暂解冻以恢复跨芯粒协同。
  - 对比单状态模拟退火（SA），SAEO 能覆盖池空间并取得 8–19% 更低的客观值。

- **Layer 2：融合与存储搜索**
  - 基因组含两部分：按拓扑序的二进制数组（1 开启新融合组，0 扩展当前组）+ 边界 DRAM 类型数组。
  - 交叉在随机切点交换两数组，变异翻转融合位或重设边界缓冲类型；适应度由 Layer 3 返回。
  - 用已知良好融合模式（如 Alwani 等早层融合）与 roofline 估计的最廉价 DRAM 做暖启动。

- **Layer 3：最优芯粒分配（改进凸包技巧）**
  - 能量建模为**分段仿射函数**：`E(T) = E_dynamic + P_static×T`（当 T ≥ T_cmp），否则为 ∞（不可行）。静态功耗可占总功耗 30%，故流水级平衡很关键。
  - **等延迟（iso-latency）分析**：固定目标级延迟 T 后各流水级解耦，可独立优化，复杂度从 O(M^P) 降到 O(M×P×Q)。
  - **改进凸包技巧**：针对分段仿射函数，按 T_cmp 排序并增量构建多个凸包，摊销 O(M log M)；查询最小值仅需两次二分。整体算法复杂度 O(P×(M log M + Q log M))——论文称这是**首个对数时间求解分段仿射函数极值的方法**。

- **Layer 4：布局布线（PNR）**
  - **Insight 4：流水线松弛是热布局资源**——非关键级具有正松弛，可通过物理分离换取散热而不损吞吐。
  - 目标函数：`c_obj = λ·ΔT/ΔT_max + (1-λ)·ΣE_i/Σ(w_i·½C_L·L_max·V²)`，约束为每链路延迟不超过关键路径预算，违反量按二次方累积。
  - 多目标模拟退火，字典序适应度 `(可行性 v, 约束代价 c_cons, 目标代价 c_obj)`；先做仅长度的预放置，再用主退火器向温度友好方向松弛。
  - 后端：热仿真改编自 MFIT（增量更新），路由器改编自 TAP-2.5D MILP（单跳）；采用 L_ref=12mm 作为 1GHz 下芯粒间连线的单周期可达长度。

### 2.3 成本与软件模型
- **成本模型**：采用 CATCH 模型联合建模晶圆/光刻成本、良率、封装、互连（混合键合、TCB）、内存控制器与 PHY；芯粒解耦因面积减小提升良率，同时摊薄 NRE。
- **软件模型**：以 **Einsum 级联**描述 BASIC 能力，四个可配置轴——(1) 层内映射、(2) 层间融合、(3) 并行策略（TP/DP/EP）、(4) 算法级优化（如 FlashAttention，留待未来工作）。模型由 PyTorch 自动下沉为 Einsum 级联。

## 6. 主要结论与发现

- **仅 8 个芯粒**（涵盖 RS/OS/WS 数据流、PIM、网络交换机）即可实现：相较同构加速器，**能耗降低 48.5%、energy×$ 降低 88.1%、EDP 降低 93.0%、EDP×$ 降低 97.8%**，且与无约束异构设计的差距**在 4.1% 以内**。
- **三条算子级洞见**被实验证实：
  - "内存墙并非真实存在"——按算子匹配最廉价 DRAM 可降存储成本 25.4–96.7% 而延迟不变。
  - "不存在通用批处理甜点"——按算子批处理可维持最高 2.0× 吞吐（如 attention 作为 BAO 会成瓶颈）。
  - "没有单一微架构通吃"——交换机芯粒对 MoE 影响最大（prefill EDP 降至 0.13×），PIM 再使 decode EDP 减半。
- **协同设计不可替代**：2×2 实验显示，随机化映射使 EDP 劣化至 8.9–9.3×，随机化池至 1.7–2.9×，即便池扩大到 N=24 差距仍存在。
- **系统级收益**：数据中心 MoE/稠密 LLM 服务中，prefill 能耗与 energy×$ 分别最多降低 **16.8%** 与 **28.7%**；边缘 AV 感知在实时约束下能耗降 **12.0%**、energy×$ 降 **23.6%**；日变负载下 Remap 相比 DU 省 **15.4%** 系统能耗与 **16.1%** EDP。
- **热布局**：热感知布局器在无关键路径违反前提下，峰值温度最多降 **4.4 K**，线长/能耗降 5.6–18%。
- **泛化与生态演进**：冻结池对多数家族泛化良好，但遇新主导瓶颈（decode 缺 PIM、MoE 缺 switch、vision 缺空间阵列）会退化；**前缀冻结微调仅加 1 个芯粒**即可让所有留出家族回到自身最优的 14.3% 以内，实现"聚焦式生态升级"。
- **成本鲁棒性**

- **成本鲁棒性**：在 1M / 2M / 3M 三档制造量下，Fengshui 的 energy×$ 与 EDP×$ 优势均保持，且随产量下降其相对同构方案的领先幅度并未消失——原因是芯粒解耦通过"面积减小→良率提升"与"NRE 跨应用摊薄"两条路径同时生效。对晶圆/光刻成本、良率参数、混合键合与 TCB 互连单价、内存控制器与 PHY 开销等 7 个关键参数的一次性敏感性扫描进一步表明，结论对这些假设不敏感：即便在不利于芯粒的取值端，协同设计收益仍显著大于零，说明其优势并非来自成本模型中的某个特定假设，而是来自架构层面的结构性收益。

## 7. 局限性与批判性评价

- **仿真而非流片**：全部性能/能耗结论来自 Timeloop + Accelergy + CENT + CACTI 的仿真链，缺少硅后验证。尤其 PIM 参数取自 CENT 规范，PIM 在真实工艺下的带宽/能耗是否与模型一致，直接决定 decode 场景（EDP 减半）的结论强度。
- **"无约束异构"仅为近似**：N=10–13 的收敛点只是有限多样性下的经验上界，而非真正的无限芯粒池最优；因此"差距在 4.1% 以内"应理解为相对该近似参考，而非绝对最优性证明。
- **软件栈迁移成本未充分量化**：论文以 Einsum 级联抽象 BASIC 能力，并声称可由 PyTorch 自动下沉，但未讨论编译器成熟度、算子覆盖缺口、以及从 CUDA 生态迁移的工程成本——这些在真实部署中往往是决定性障碍。
- **算法级优化留白**：四个可配置轴中，算法级优化（如 FlashAttention）明确"留待未来工作"，意味着当前对比可能低估了在 GPU 上通过算法重写获得的收益，从而高估了硬件定制的相对优势。
- **搜索与特征化开销**：一次性 185K 次 Timeloop mapper 运行、每目标 2.4–2.5 小时的池搜索，虽在离线设计场景可接受，但对快速迭代的设计流程仍构成门槛；且论文未报告搜索所用机器配置，复现成本难以精确评估。
- **后端简化**：热仿真改编自 MFIT 并采用增量更新，路由器改编自 TAP-2.5D 单跳 MILP，L_ref=12mm 为理想化单周期假设；真实封装中的串扰、电源完整性、TSV/键合应力等未纳入。

## 8. 总体评价与启示

- **方法学贡献**：(1) 首次将"芯粒池的构成"从静态约束提升为与加速器架构联合优化的设计变量，正面回应芯粒生态的"循环依赖"；(2) 提出针对分段仿射代价函数的改进凸包技巧，实现对数时间极值查询，将芯粒分配复杂度从 O(M^P) 降至 O(P×(M log M + Q log M))；(3) 构建四层嵌套协同设计框架，把池搜索、融合/存储、芯粒分配、物理布局统一在同一目标下。
- **实践启示**：论文最强的操作性结论是"**聚焦式生态升级**"——当新工作负载暴露出主导瓶颈（如 decode 缺 PIM、MoE 缺 switch、vision 缺空间阵列）时，只需前缀冻结微调并新增 1 个芯粒，即可让留出家族回到自身最优的 14.3% 以内。这为芯粒生态的渐进演化提供了可执行的路线图，而非要求一次性设计完美池。
- **证据强度**：与真实 GPU（RTX PRO 6000 Blackwell）实测对比、与 SCAR/Gemini 在同基础设施下复现、2×2 因子实验隔离池与映射两维贡献、随机基线采样同一设计空间——这些设计使结论的公平性优于多数同类工作，主要不确定性集中于仿真保真度与 PIM 假设。
- **潜在影响**：若芯粒生态与先进封装（混合键合、2.5D/3D）按预期成熟，本文的"算子级解耦 + 生态协同设计"范式可能成为 BASIC 加速器从学术概念走向产品化的重要中间形态。
