## 摘要
BrainScaleS-2（BSS-2）神经形态架构将对脉冲神经网络（SNN）原语的模拟仿真与紧密耦合的模数转换器（ADC）和数字处理单元相结合。这些模拟 SNN 原语是固定的硬件资源，无法复用，从而将可仿真的网络规模限制为物理硬件副本的数量。为克服模拟设计在扩展方面的挑战，基于芯粒的设计提供了一种有前景的方法，相较于单片扩展具有成本和灵活性优势。实现基于芯粒的 BSS-2 架构需要一个互连网络来处理两类不同的流量：容错流量（如脉冲）和不容错流量（如配置数据或处理单元交换的数据）。本文提出了一种用于 BSS-2 架构的路由芯粒设计，可在二维网格拓扑中互连多个 BSS-2 单元。两类流量均复用在单个宽并行裸片到裸片链路上。利用 SNN 的容错性，脉冲以无保护且同步的方式传输，接收侧的到达时间直接决定脉冲的突触前时间。相反，不容错数据传输通过点对点自动重传请求协议得到保护，并使用基于信用的流控。这些设计选择在仿真中得到验证：在 $1 \times 10^{-10}$ 误码率下，对于替代梯度训练用例，在广泛的脉冲与受保护流量比例范围内，所提出的设计能够维持 $95\,\%$ 的链路带宽利用率，且对脉冲时序抖动影响很小。

## Abstract
The BrainScaleS-2 (BSS-2) neuromorphic architecture combines analog emulation of spiking neural network (SNN) primitives with tightly coupled ADCs and digital processing units. These analog SNN primitives are fixed hardware resources that cannot be multiplexed, limiting the emulated network size to the number of physical hardware copies. To overcome the challenges of scaling analog designs, chiplet-based designs offer a promising approach with cost and flexibility advantages over monolithic scaling. Implementing a chiplet-based BSS-2 architecture requires an interconnection network that handles two distinct classes of traffic: error-tolerant traffic such as spikes and error-intolerant traffic like configuration data or data exchanged by the processing units. This work presents the design of a routing chiplet for the BSS-2 architecture that enables interconnection of multiple BSS-2 units in a 2D mesh topology. Both traffic classes are multiplexed over a single wide parallel die-to-die link. Exploiting the fault tolerance of SNNs, spikes are transmitted unsecured and synchronously, with the arrival time on the receiving side directly determining the pre-synaptic time of the spike. Conversely, error-intolerant data transmission is secured by a point-to-point Automatic Repeat Request protocol and uses credit-based flow control. These design choices are validated in simulation, where the proposed design can sustain $95\,\%$ link bandwidth utilization for the use case of surrogate gradient training across a wide range of spike-to-secured traffic ratios under a $1 \times 10^{-10}$ bit error rate with little impact on spike timing jitter.

# 论文总结：面向基于芯粒的 BrainScaleS 神经形态系统扩展的统一互连网络

## 1. 核心问题与研究动机

- **背景**：BrainScaleS-2（BSS-2）是采用 65 nm 工艺的混合信号神经形态 SoC，包含模拟核心（连续时间仿真最多 512 个神经元、131 072 个突触）、片上并行 ADC 与紧耦合嵌入式处理器，相对生物实时有 1000× 加速比。
- **根本矛盾**：模拟 SNN 原语是**固定硬件资源、不可复用（cannot be multiplexed）**，可仿真的网络规模严格等于物理硬件副本数量；而模拟核心受面积约束，无法像数字处理器那样从先进工艺节点获益，因此**单片（monolithic）扩展既昂贵又低效**。
- **为何选择芯粒（chiplet）**：拆分大裸片可提升良率、便于功耗/性能分档（binning）、支持更细粒度的模块化设计与设计空间探索，并允许不同部分使用不同工艺节点——对模拟/混合信号部分尤其有利。
- **互连的核心挑战**：扩展后的系统必须同时承载两类本质不同的流量：
  1. **事件消息（event）**：脉冲无载荷，信息编码在时间中；需最小且**确定性延迟**以保持相对时序，但可容忍少量丢失（借鉴生物突触传递的不可靠性）；模拟计算连续时间运行不可暂停，故系统需**全局异步**；拥塞会改变脉冲时序，因此拥塞脉冲可被丢弃。
  2. **非事件消息（non-event）**：配置数据、处理器间消息等，**必须保证可靠性与正确性**，否则系统不可用。
- **已有工作不足**：静态划分链路带宽的方案在负载不均时表现差；已有 BSS-2 互连方案（FPGA 星型路由 [16]）只描述事件传输、无可靠数据通道；EXTOLL 方案 [17] 将事件打包并加时间戳，带来额外延迟与开销。
- **本文目标**：设计一个**统一的互连网络（IN）**，用专用路由芯粒在 2D Mesh 拓扑中互连多个 BSS-2，并在**单条宽并行 die-to-die 链路**上复用两类流量。

## 2. 方法论

### 2.1 核心思想

- **物理载体**：采用文献 [8] 的 C2C 链路，实测 BER ≤ 1×10⁻¹⁰、单链路 2 Gbit/s；受键合与面积限制，每方向约 11 条链路，**每端口每方向总带宽 22 Gbit/s**。
- **动态带宽划分而非静态划分**：在 phit（物理传输单元）级别分流，每个 phit 带一位类型标志；加权优先级仲裁器在事件与非事件 phit 之间仲裁，**默认优先事件**，同时为不可靠性要求高的非事件流量**保证可配置的最小吞吐**。
- **差异化可靠性策略**：利用 SNN 的容错性，事件消息**无保护、同步传输**，接收侧到达时间直接决定突触前时间（避免时间戳开销）；非事件消息则用**点到点 ARQ + CRC** 保证可靠。

### 2.2 关键技术细节

**物理层与组帧**
- C2C 链路组织为并行总线，DDR 工作，每 1 ns 时钟周期发送一个 **22 bit phit**。
- 多个非事件 phit 被合并为**固定长度 flit**；每个 phit 携带一个 **framing bit** 用于收发两侧 gearbox 同步（选择"该 phit 是某非事件消息的最后一个 phit"作为语义）。
- 设置专用 framing bit 而非依赖 CRC 同步，是为了**在 phit 出错后能快速恢复同步**。

**头编码与 FEC（Table I）**
- 类型位与 framing bit 的误判等价于整 phit 的随机比特翻转，用 CRC 保护代价过高，故用 **Hamming-(7,4) FEC** 保护单比特翻转。
- 将 phit 成对分组、共享头部以摊薄开销：**事件 phit 开销 3 bit，非事件 phit 开销 4 bit**。
- 采用构造性前缀码：含两个事件的 phit 对仅需 **6 bit** 编码，其余组合需 7 bit；任意两个码字**至少相差 3 bit**，故可纠正单比特翻转。
- 事件载荷最终为 **19 bit**（AER 编码），可提供 2¹⁹ = 524 288 个神经元的唯一标签，即至少 **1024 片 BSS-2**；实际系统中每片只见全局神经元子集，可用非唯一标签进一步扩大规模。

**非事件消息的错误检测与控制**
- 每个 **flit = 90 bit**，含 **7 bit CRC**，可提供 **汉明距离 3** 的保护；检测与控制在 flit 级进行。
- 链路级 **ARQ**：每个 flit 含序号；接收成功由专用 **ACK flit** 通告；CRC 检错后由接收方发送 **NACK flit** 触发重传，或由超时触发重传（针对未确认的未决 flit）。设计目标是**最小化错误恢复的延迟影响**。

**流控与路由**
- 采用**基于信用的流控（credit-based）**跨芯粒传递背压，信用计数随 ACK flit 一并回传。
- **虫洞（wormhole）路由**：一个或多个 flit 组成 packet，首个 flit 携带路由信息决定输出端口；对 packet 长度**不设人为限制**以最小化路由信息开销。
- 选用**确定性维度序 X-Y 路由**，保证每对源-目标之间 packet 顺序保持，简化 AXI / OCP 等有顺序保证协议的隧道化，接收侧无需重排序缓冲；但若源允许对多个目标存在多个未决读，读响应仍需重排序缓冲。
- **事件路由器不在本文范围内**；评估中使用一个简单的**广播事件路由器**代替。

## 3. 实验设计

- **总体方法**：将设计用可综合 SystemVerilog / Amaranth HDL 实现，先做**大量形式化验证**确认正确性；再经 **CXXRTL 编译为周期精确 C++ 模型**，与 C++ 高层模型（物理链路、事件/非事件流量）联合仿真。物理链路建模为**固定延迟的有损信道 + 固定 BER**。

- **实验一：非事件消息最大延迟（Fig. 3）**
  - 场景：模仿 **hardware-in-the-loop 代理梯度（surrogate gradient）训练**——前向在模拟基底执行，片上 ADC 采样膜电位作为宿主反向传播输入，故非事件消息（ADC 采样）为**恒定速率**；事件消息按**每 C2C 链路的 Bernoulli 过程**生成。
  - 配置：n = 4 或 6 个路由芯粒排成一行，到 FPGA 的带宽假设无限；**BER = 0**；物理传输延迟刻意设为较大的 **135 ns**；输入缓冲与 ARQ 发送窗口各 **64 flit**。
  - 结果：低事件率下延迟接近物理传输延迟，n = 4 时最小 **610 ns**；事件率升高时因拥塞与事件优先级导致延迟上升；无法承受所施加速率的参数点用红色标出。

- **实验二：非事件消息的可持续带宽与 MTBF（Fig. 4）**
  - 场景：链路 **BER = 1×10⁻¹⁰**。因传输错误必然触发重传，**绝对带宽保证不可能**，故改测"无法维持给定带宽"的**平均无故障时间（MTBF）**。
  - 方法：对 **200 次随机注入的比特翻转**，测量稳态缓冲水位恢复所需的最长时间 t_recover，再由第二次传输错误落在该窗口内的概率给出 MTBF 上界：
    - **MTBF = 1 / (t_recover · B² · ρ²)**，其中 B 为链路带宽，ρ 为比特率。
  - 配置：ARQ 发送窗口与输入缓冲各 64 flit；物理链路延迟 **85 ns**（选为"在 95% 链路利用率下单次错误不会立即填满 ARQ 缓冲"的最大延迟）；因该流量模式下路由不影响错误行为，只仿真**单条双向 C2C 链路**。

- **实验三：事件消息延迟与抖动（Fig. 5）**
  - 使用与**当前 BSS-2 硬件版本及 FPGA 设计**的端到端联合仿真；链路延迟 **4 ns**；**不注入错误**（事件无错误控制）。FPGA↔BSS-2 接口被复用为 FPGA↔路由芯粒接口。
  - 三种情形：0 跳基线（仅 FPGA→路由芯粒链路，红）；1 跳穿越两条 C2C 链路且**不注入**非事件流量（绿）；1 跳穿越两条 C2C 链路且**以最大允许速率注入**非事件流量（蓝）。
  - 事件率取 125.00 / 62.50 / 41.67 / 31.25 MHz，共统计 **10 000 条事件消息**的往返延迟；时间戳粒度受 125 MHz FPGA 时钟限制。
