## 摘要
数字存内计算（CIM）通过将计算逻辑直接集成到存储阵列中，为加速深度神经网络（DNN）提供了一种很有前景的解决方案。然而，由于刚性 CIM 阵列结构施加的严格数据复用约束，将现代 DNN 算子映射到 CIM 加速器上往往会导致严重的阵列利用率不足。我们观察到，现代 DNN 中的数据复用会形成超平面结构，这些超平面通常沿非轴向方向分布，因而无法被仅利用轴对齐复用的传统映射方法发现。在这项工作中，我们提出 PolyCIM，一种面向 CIM 架构的基于多面体的编译框架，它通过仿射变换系统地揭示并重新对齐这些超平面。PolyCIM 提供了一种统一抽象，能够高效表示多样化的 DNN 工作负载和数字 CIM 架构。通过数据复用揭示、计算映射和数据移动优化，PolyCIM 为 CIM 架构生成映射，从而实现更优的阵列利用率和性能。实验结果表明，PolyCIM 在宏单元利用率上最高提升 4 倍，并实现 3.2 倍加速，有效弥合了现代 DNN 算子与 CIM 架构之间的差距。

## Abstract
Digital Compute-in-Memory (CIM) presents a promising solution for accelerating deep neural networks (DNNs) through the integration of computational logic directly within memory arrays. However, mapping modern DNN operators to CIM accelerators often results in severe array underutilization, due to the strict data reuse constraints imposed by the rigid CIM array structure. We observe that data reuse in modern DNNs forms hyperplane structures often oriented along non-axial directions, rendering them invisible to conventional mapping methods that only exploit axis-aligned reuse. In this work, we propose PolyCIM, a polyhedral-based compilation framework for CIM architectures that systematically exposes and realigns these hyperplanes through affine transformations. PolyCIM provides a unified abstraction capable of efficiently representing both diverse DNN workloads and digital CIM architectures. Through data reuse exposure, computation mapping, and data movement optimization, PolyCIM generates mappings for CIM architectures that achieve superior array utilization and performance. Experimental results show that PolyCIM delivers up to $4\times$ improvement in macro utilization and $3.2\times$ speedup, effectively bridging the gap between modern DNN operators and CIM architectures.

## 1. 核心问题与整体含义

- **背景**：深度神经网络（DNN）持续增大，数据搬运成为传统架构的主要性能瓶颈。存内计算（CIM）通过将计算逻辑嵌入存储阵列来加速矩阵向量乘法（MVM），其中数字 CIM 相比模拟 CIM 避免了 ADC 开销与模拟非理想性，更适合现代 DNN 负载。
- **核心问题**：数字 CIM 阵列结构刚性，要求每行原子激活、输入沿行广播、部分积沿列累加。主流 im2col 映射将权重滤波器展开到阵列列、输入激活沿行广播，导致阵列利用率直接取决于共享同一输入激活的滤波器数量。对于深度卷积、分组卷积等现代算子，该数量常小于阵列列数，造成严重阵列欠利用。
- **关键观察**：现代 DNN 中的数据复用往往在迭代空间中形成超平面结构，且常沿非轴向方向分布。传统仅利用轴对齐复用的映射方法无法发现这些机会，而 DNN 操作数访问是循环索引的仿射函数，因此可通过仿射变换系统性地将这些超平面对齐到阵列轴。
- **整体含义**：PolyCIM 旨在弥合现代 DNN 算子与刚性数字 CIM 架构之间的映射鸿沟，通过多面体编译自动暴露非轴向数据复用，提升宏利用率和端到端性能。

## 2. 方法论

- **核心思想**：将 CIM 映射问题形式化为多面体变换问题，自动推导仿射变换，使数据复用超平面对齐到 CIM 阵列的行/列方向，从而把隐藏复用转化为可被硬件直接利用的并行性。
- **统一抽象**：
  - 算子抽象为四元组 ⟨D, A_I, A_W, A_O⟩，其中 D 为迭代空间，A_I/A_W/A_O 分别捕获输入、权重、输出的访问关系。可表示标准卷积、深度卷积、分组卷积、空洞卷积等。
  - CIM 硬件抽象为 ⟨D_CIM, A_in_reg, A_mem, A_out_reg⟩，D_CIM 索引 (i_m, i_r, i_c) 即宏、行、列。输入广播关系仅索引 (i_m, i_r)，输出累加关系仅索引 (i_m, i_c)，局部存储关系保留全三元组。
- **优化流程**（三阶段）：
  1. **数据复用暴露**：
     - **预平铺（Pre-Tiling）**：在仿射变换前分解迭代轴，控制迭代空间膨胀。对长度为 s_k 的轴，枚举其因子分解，使用混合进制分解替换原轴。通过轴排除和对称去重剪枝候选空间，选择使后续仿射变换引起的迭代空间膨胀最小的方案。
     - **仿射调度（Affine Schedule）**：将变换发现问题重构为基搜索问题。对每个操作数数组 M，构造候选基集合 B_M = {b | A_M b = 0 ∧ −m < b < m}，即满足方向约束（沿基方向访问同一数据）和度数约束（至少一步复用）的向量。从 B_I ∪ B_W ∪ B_O 中选择 n 个线性无关向量，至少一个来自 B_I、一个来自 B_O。构造变换矩阵 B = [b1,…,bn]，求逆 P = B^{-1}，按行取分母最小公倍数整数化，得到仿射调度 S_Aff = {j → Pj}。
  2. **计算映射**：
     - **合并调度（Coalescing Schedule）**：将多个输入复用轴合并为统一列维度 c，多个输出复用轴合并为统一行维度 r，采用混合进制线性化。非复用轴保留为外层 t 维度。
     - **后平铺调度（Post-Tiling Schedule）**：将合并后的 r、c 按物理宏尺寸 R×C 平铺，内层 (r_i, c_i) 直接映射到宏行列，外层 (r_o, c_o) 形成宏块循环。
     - **多宏映射**：按优先级将外层循环分配到宏维度：先输出复用轴（部分和位宽大、搬运代价高），再输入复用轴（可共享广播），再非复用轴，最后权重复用轴（需足够存储时复制权重）。超出宏数量时分裂轴。
  3. **数据移动优化**：
     - **迭代空间对齐布局**：根据变换后访问关系构造 T_align，使连续迭代访问连续内存位置，离线生成布局变换代码。
     - **数据移动调度**：建立整数优化问题，决策循环重排矩阵 X 和每个操作数的缓冲点向量 L。利用对数线性化将缓冲区大小与传输次数的乘积转化为求和，目标是最小化各操作数、各存储层级的数据移动量之和，约束为容量限制，用混合整数求解器求解。
- **目标函数**：最大化平均宏利用率 util = MACs / (P_MAC × cycles)，等价于在给定算子与硬件配置下最小化执行周期。

- PolyCIM 在算子级实现 1.9×–8.2× 加速，平均 4.9×；宏利用率从 im2col 常低于 10% 提升至最高 75%。
