## 摘要
我们提出了 MEGATRON，一款采用 28nm FD-SOI CMOS 技术的异构边缘 GenAI 系统级芯片，它将基于 4Mi 单元相变存储器（PCM）阵列的非易失性模拟存内计算引擎与基于 RISC-V 的数字灵活神经处理单元相结合。MEGATRON 在使用 RISC-V 处理器时实现高达 3.5 TOPS/W，在使用 PCiM 时达到 57.5 TOPS/W，并在 4 位有效权重精度下实现 1.52 Mparam/mm² 的存储密度。

## Abstract
We present MEGATRON, a heterogeneous Edge GenAI System-on-Chip in 28nm FD-SOI CMOS technology combining a non-volatile analog in-memory-computing engine based on a 4Mi-cell phase-change memory (PCM) array with a digital RISC-V-based flexible neural processing unit. MEGATRON demonstrates up to 3.5 TOPS/W using the RISC-V processors and 57.5 TOPS/W with PCiM, at a storage density of 1.52 Mparam/mm${}^2$ with 4-bit effective weight precision.
